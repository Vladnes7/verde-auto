# VERDE AUTO

[Репозиторий на GitHub](https://github.com/Vladnes7/verde-auto)

Большой русскоязычный портфолио-концепт компании по подбору, покупке и доставке автомобилей из Китая в Россию.

## Запуск

```sh
npm install
npm run dev
```

Сборка: `npm run build`. Предпросмотр: `npm run preview`. Синтаксис: `npm run check`. Браузерная проверка: `npm run test:browser` (Google Chrome и сайт на порту 4173).

## Текущая версия

- 94 самостоятельные HTML-страницы: главная, каталог, бренды, услуги, доставка, компания, база, журнал, FAQ и контакты, а также страницы моделей и материалов.
- 72 модели и комплектации, по 12 BMW, Mercedes-Benz, Porsche, Li Auto, Voyah и Zeekr. У каждой три отдельных ракурса, описание, характеристики и демонстрационная цена.
- Полноэкранная страница автомобиля с переходами между фотографиями, клавиатурой и свайпом. Каталог с поиском, фильтрами и постепенной загрузкой карточек.
- Видео пользователя без внешней рамки и без кнопок воспроизведения. Шесть логотипов, движущаяся лента, яркие зелёные сцены и раскрывающийся веер автомобилей.
- Карта Евразии с географическими данными Natural Earth и движением автомобиля по примеру маршрута Пекин — Москва.
- Отдельные страницы компании, услуг и вымышленной базы с шестью сгенерированными визуализациями, включая фасад с вывеской VERDE AUTO, зал и зону передачи.
- Мгновенные обычные ссылки с нативной анимацией перехода между документами. Отмена анимации не блокирует навигацию; в неподдерживающих браузерах страницы открываются обычным способом. Поддержан reduced motion.
- Локальные кириллические шрифты Manrope, Unbounded, Cormorant Garamond и Caveat. Scrollcraft и GSAP, доступное полноэкранное меню и вариант reduced motion.

## Содержание и исходники

- `src/catalog.js` — каталог, бренды, услуги, FAQ и журнал. Первые 24 модели берутся из `src/cars.js`.
- `src/collection-expansion.js` — 24 дополнительных модели и иллюстративные конфигурации версии 3.
- `src/pages.js` — общие компоненты и семантическая разметка всех страниц.
- `src/site.css` — актуальный дизайн и адаптивная версия.
- `src/site.js` — анимации, фильтры, галереи, меню и форма.
- `src/geography.js` — карта, координаты и маршрут.
- `vite.config.js` — генерация отдельных HTML-файлов.
- `public/media/catalog/` — 216 фотографий; `public/media/hub-*.jpg` и `salon-*.jpg` — визуализации базы и салона.
- `docs/2026-10-24-multipage-redesign.md` — требования и структура.
- `scrollcraft/builds/verde/REVISION-3-VERIFICATION.md` — актуальная проверка; предыдущие отчёты сохранены как история.

Старые `src/main.js`, `src/styles.css` и `src/motion.js` оставлены как исходники первой версии и не входят в текущую сборку.

## Публикация и демонстрационные данные

Публикуется содержимое `dist/`. Статический хостинг должен обслуживать каталоги через `index.html`; серверный API не требуется. Шрифты, логотипы и медиа локальные.

VERDE — вымышленный бизнес. Изображения иллюстративные, цены и комплектации демонстрационные. Контакты и социальные сети — заглушки. Форма сохраняет черновик в текущей сессии, позволяет скопировать его или открыть почтовую программу; сама сообщение не отправляет. Перед реальным запуском нужно подключить реальные контакты и обработчик заявок и проверить каталог.
