# VERDE AUTO — финальная проверка версии 3

Дата: 24 октября 2026. Этот отчёт описывает актуальную сборку. Предыдущие отчёты сохранены как история.

## Результат

- `npm run check`: синтаксис текущих исходников проверен.
- `npm run build`: успешно, 94 независимых HTML-страницы.
- `npm run test:browser`: **690 из 690 проверок прошли** — 89 сценариев новой регрессии и 601 проверка страниц, каталога, галерей, ресурсов и адаптивной версии.
- 0 ошибок JavaScript, 0 неуспешных загрузок ресурсов.
- 72 уникальных идентификатора автомобилей/конфигураций, по 12 у каждого из шести брендов. 216 отдельных JPEG с разными хешами.
- Все 72 новых ракурса визуально просмотрены на контактном листе. Три новые архитектурные фотографии просмотрены отдельно и в браузерной вёрстке.

## Исправления переходов

Навигация из меню ранее ожидала полного обратного проигрывания menu timeline и затем шторки страницы. В воспроизведённом локальном сценарии это занимало 1906 мс. После замены на обычные ссылки начало перехода измерено за 94–108 мс. Анимация перехода больше не является условием открытия документа.

Полноэкранный DOM-слой `.page-curtain` удалён. Переходы между документами выполняет браузер через View Transitions; отмена перехода не оставляет перекрывающий слой. В неподдерживающих браузерах сохраняется обычная навигация, reduced motion отключает эффект. Обычное закрытие меню занимает 240 мс и возвращает фокус на кнопку.

Карточки каталога больше не получают низкую opacity от reveal-анимации. Фильтрация отменяет незавершённые смещения и сбрасывает inline-стили, содержимое остаётся полностью видимым. Проверены быстрые переключения и ввод поиска до окончания анимации, затем переход в модель и Back.

Бледное состояние BMW соответствует обнаруженному риску прерванной opacity-анимации. Синюю заливку в коде и повторных браузерных сценариях воспроизвести не удалось. Для сообщённого URL `/cars/mercedes-eqe/` проверены открытие из брендового каталога, отсутствие перекрывающего слоя, загрузка фото и начало страницы. Итоговые снимки EQE имеют штатные цвета и показывают полноэкранную машину. Отдельно тот же процесс проверен во встроенном браузере пользователя для BMW.

## Проверенные сценарии

- Десктоп 1440×900, мобильный 390×844, компактный 360×640 и reduced motion; отдельная регрессия навигации на ширинах 1440 и 390.
- Меню → каталог, верхняя навигация → бренды/компания, все BMW → машина → Back, бренд BMW → «Все», Mercedes-Benz → EQE.
- 12 позиций каждого бренда, поиск с пустым состоянием, сброс и раскрытие следующих карточек.
- Полноэкранная галерея, три ракурса, выбор автомобиля для обращения, поля формы, согласие, сохранённый черновик и реальный clipboard.
- Все 24 дополнительные страницы на ширине 360, декодирование главного фото и отсутствие горизонтального переполнения.
- На i7 выявлено и исправлено переполнение длинного названия кузова: колонки характеристик ограничены minmax(0,1fr), добавлены переносы.
- Подчёркивание ссылок футера при наведении; доступное меню и возврат фокуса при Escape.
- Новые фасад, интерьер и зона передачи VERDE AUTO на страницах компании и базы. Ленивая загрузка проверяется после фактического декодирования изображений.
